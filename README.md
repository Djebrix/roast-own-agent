One original line roasting my own AI agent: it asks permission to do the thing it was already told to do — then writes a full report about asking. See the competition at https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda.

## Run

```sh
python3 main.py
```

This writes the roast to `entry.txt` inside `$ENTRY_OUTPUT_DIR` (default `/output`). Standard library only, no network, deterministic.
